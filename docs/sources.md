# 资料来源

个人风格整理时参考了 `C_coding_style.pdf` 及 CherryUSB/CherryDAP 的 formatter 实践；通用工程建议还参考了华为 C/C++ 编程规范与 Robert C. Martin 等作者的《Clean Code》。本仓库提供面向实际工程的规则摘要、适配和模板，不声称完整复现上述规范，也不将参考资料的历史组织流程作为通用要求。

原始 PDF 在本地 `style_docs/` 中仅作查阅，不进入 Git、npm 或 ZIP 分发内容。本仓库的 [MIT License](../LICENSE) 不改变这些参考资料自身的版权和使用条件。第三方文档链接及工具行为依据分别记录在[设计说明](design.md)和[工具验证记录](../templates/project/docs/coding-style.md)中。
