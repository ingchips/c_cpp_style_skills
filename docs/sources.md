# 资料来源

个人风格整理时参考了 `C_coding_style.pdf` 及 CherryUSB/CherryDAP 的 formatter 实践；通用工程建议还参考了华为 C/C++ 编程规范与 Robert C. Martin 等作者的《Clean Code》。本仓库提供面向实际工程的规则摘要、适配和模板，不声称完整复现上述规范，也不将参考资料的历史组织流程作为通用要求。

## 原始参考文档

- [个人 C 编码风格](https://github.com/ingchips/c_cpp_style_skills/blob/main/style_docs/C_coding_style.pdf)
- [华为 C 语言编程规范](https://github.com/ingchips/c_cpp_style_skills/blob/main/style_docs/华为技术有限公司C语言编程规范.pdf)
- [华为 C++ 语言编程规范](https://github.com/ingchips/c_cpp_style_skills/blob/main/style_docs/华为技术有限公司C++语言编程规范.pdf)
- [Clean Code](https://github.com/ingchips/c_cpp_style_skills/blob/main/style_docs/clean-code.pdf)

原始 PDF 集中在 `style_docs/`，随 Git 仓库提供查阅，不进入 npm 或 ZIP 安装包，也不作为模型默认加载的指令。本仓库的 [MIT License](../LICENSE) 适用于原创内容，不改变这些参考资料自身的版权和使用条件。第三方工具文档链接及行为依据分别记录在[设计说明](design.md)和[工具验证记录](../templates/project/docs/coding-style.md)中。
